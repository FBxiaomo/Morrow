# 末时钟 · Morrow

**末时钟 · 天气氛围与专注时钟**。为学习、办公与休息提供低干扰的全屏时钟，保留天幕、数字工作室、窗边、静谧编辑四种独立场景与本机配置。

## 使用

**在线版**：打开 <https://fbxiaomo.github.io/Morrow/>（GitHub Pages 自动部署，与源码 `main` 分支同步）。支持浏览器「安装」为独立桌面应用；核心界面可离线重新打开，实时天气需联网。

**本地开发**：

```powershell
npm install
npm run dev
```

打开 `http://127.0.0.1:5190/`。鼠标移动唤醒工具条；触屏和键盘操作时不会自动隐藏。点击「主题」切换场景，「专注」进入完整计时流程，「个性化」调整当前空间，眼睛图标进入纯净显示。

### 0.2.1 体验与可读性打磨

- 设置面板改为不透明底色。此前玻璃面板只有 48%–65% 不透明度，背后的巨大数字会透进标题与说明文字。
- 修复静谧编辑在 1024×768、1366×768 下世界时钟压住时钟数字与秒进度条的问题；世界时钟改为独立右栏，并按高度收窄数字。
- 数字工作室的正文与辅助文字整体加深，并在浅色墙面上补足局部承托，界面小字达到 WCAG AA 对比度。
- 界面字号下限提升到 11px；秒说明、世界时钟、主题卡片说明与设置说明不再使用 8–10px。
- 世界时钟支持内置城市、英文常用名与 IANA 时区；无法识别的条目会说明原因，不再显示 `--:--`。设置内输入时即时校验。
- 天空主题为数字增加柔和托底，亮云背景下的白色细字更稳定。

### 0.2.0 产品改造

- 发布演示级视觉：真实场景、大字形时间、玻璃工具条、克制的主题转场；辅助文字和点击目标整体提升。
- 完整专注闭环：任务意图、15 / 25 / 45 分钟快捷选择、开始 / 暂停 / 继续 / 结束、到时页面与系统通知、今日本地记录。
- 长时间离开不再连续补算多段专注；返回后暂停等待确认。连按空格不会结束专注。
- 纯净显示只保留时间与用户选择的信息，点击右下角或按 H 可退出。
- 横屏采用独立紧凑构图，先移除装饰与次要信息，避免时间、日期、世界时钟和工具条重叠。
- 设置分为主题、外观、天气、显示、通用；主题预览使用真实场景与当前时间。
- 支持屏幕常亮、版本化 JSON 配置导入导出、自选背景删除、本机数据二次确认清空。
- 设置写入失败会明确显示「仅本次有效」，可重试或导出备份。
- 生产版本注册离线应用缓存，核心界面可离线重新打开；实时天气仍需网络。

### 主题与天气

- 主题风景、纯色、渐变、本地图片；本地图片保存在 IndexedDB，按主题独立保存。
- 真实天气 / 自选天气；晴、多云、阴、雨、雪、雾、雷雨；白昼、日落、夜晚。
- 城市搜索提供候选列表，定位仅主动点击后请求；天气缓存 30 分钟，断网明确标记上次天气。
- 轻量与写实两档画质；窗边支持 WebGL 玻璃雨，失败时自动回退。
- 完整动态 / 轻量动态 / 静态，遵循系统减少动态效果设置，页面隐藏时暂停背景绘制。
- 日期、农历、月相、世界时钟与麦克风律动均可配置。麦克风为实验功能，音频只在本机处理。

| 快捷键 | 操作 |
| --- | --- |
| 1–4 | 切换四个主题 |
| S / Esc | 设置 / 关闭或退出纯净显示 |
| F | 全屏 |
| H | 纯净显示 |
| T | 12 / 24 小时制 |
| 空格 | 打开专注、暂停或继续 |
| M | 请求启用或关闭麦克风律动 |

## 代码结构

- `src/main.ts`：应用装配、快捷键、常亮与离线注册。
- `src/ui/dashboard.ts`：时间、场景信息、工具条与活跃专注状态。
- `src/ui/focus.ts`：任务专注、到时提醒与完成回顾。
- `src/ui/customizer.ts`：主题画廊、设置、城市搜索、图片与数据管理。
- `src/data/pomodoro.ts`：时间戳驱动的计时状态与本地记录。
- `src/data/cities.ts`：世界时钟的城市、英文名与 IANA 时区解析，含无效条目原因。
- `src/data/settings.ts`：设置校验、持久化状态与本机存储。
- `src/atmosphere/`：天气、摄影背景、数字碰撞与窗边玻璃渲染。
- `public/sw.js`：核心界面离线缓存；不拦截第三方天气请求。

## 文档体系

本仓库采用 SDD（规范驱动开发）文档体系，英文名 **Morrow**（2026-11-22 起统一，前称 Horloge）：

- `AGENTS.md`：AI 编程代理的协作入口（harness 文档），含硬性规则与测试须知。
- `docs/项目规范.md`：工程规范单一真相源——命名、分层、存储注册表、CSS、测试、发布。
- `specs/README.md`：SDD 方法论与目录结构（steering / capabilities / changes 三层）。
- `specs/capabilities/<域>/spec.md`：八个能力域的正式行为规格（当前实现的事实源）。
- `specs/changes/`：变更提案模板与进行中的提案（含 Horloge→Morrow 标识迁移提案）。
- `docs/v2设计.md` … `docs/v6窗边玻璃雨.md`：历史演进决策，只读。

天气数据来自 [Open-Meteo](https://open-meteo.com/)。当前仍为直接公共接口接入，正式商业发布前需更换符合商用条款的服务方案，并将密钥、限流与预算控制放到可信服务端。使用「当前位置」时，坐标到地名的解析走 [BigDataCloud](https://www.bigdatacloud.com/) 的免密钥客户端接口。本项目不包含支付、账户或云同步。
