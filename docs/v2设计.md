# 粒子桌面时钟 · 完整计划 v2.0（推翻重来版）

> 三轮问答后的最终方案。任何实现都以本文档为准；改动先改文档再改代码。

## 0. 定位

**全屏桌面时钟。应用即桌面。**
画面不响应鼠标（除了设置面板），只对**真实世界**作出反应：
时间 → 色温，天气 → 运动与前景，音乐 → 起伏，一天的节奏 → 呼吸。

设计原则（不可违背）：
1. **克制**：亮度预算、无泛光、安静模式下依然能用
2. **有信息量**：画面反映真实状态，不做纯装饰
3. **可个性化**：样式即插件，设置面板完整且由数据生成
4. **降级优雅**：天气离线、麦克风拒绝、配置缺失，都不影响时钟本体

## 1. 决策记录（三轮问答）

| 问题 | 决定 |
| --- | --- |
| 显示内容 | 时间 + 秒、日期 + 星期、天气、番茄钟、世界时钟、农历/节气/月相 |
| 视觉主体 | 可个性化的样式插件；首批：**星尘 dust、轨道 orbit、声波 wave** |
| 交互 | 画面**零鼠标响应**；仅环境动态 + 键盘 + 设置面板 |
| 自定义 | **完整设置面板**（样式/外观/内容/天气/音乐/番茄/屏保），实时生效，持久化 |
| 色温 | **中等偏移**：四时段明显可辨的色彩语言 |
| 天气视觉 | **混合**：背景粒子雨丝 + 前景玻璃水珠滑落 |
| 天气来源 | **设置城市 + 显示温度**（Open-Meteo，免 key） |
| 字体 | **衬线体**（Didot / Bodoni / Playfair 类），可在设置里换 |
| 番茄钟 | **独立样式**（切到倒计时样式才有，与时钟解耦） |
| 音乐律动 | **麦克风输入**，本地 FFT 分析，不上传 |
| 屏保 | 无操作后只留时间，其余隐去，粒子慢呼吸 |
| 世界时钟 | **小字副行**「纽约 06:32」压在主时间下方，多城市轮换 |
| 路线图排除 | 整点报时、纪念日倒数（本轮不做） |

## 2. 架构

```text
engine.ts        渲染器、相机、拾取、rAF、色温调度
field.ts         粒子缓冲、物理、着色器、亮度钳制
palette.ts       视觉预算（硬性数字）
data/
  clock.ts       日期时间农历节气（含时区）
  weather.ts     Open-Meteo + 城市检索 + 缓存 + 降级
  music.ts       麦克风 + AnalyserNode + 频段包络
  pomodoro.ts    状态机（时间戳计时，localStorage）
  settings.ts    设置 schema + 持久化 + 变更广播
styles/
  registry.ts    样式注册与切换
  dust.ts        星尘（基准样式）
  orbit.ts       轨道
  wave.ts        声波
  pomodoro.ts    番茄倒计时样式
layers/
  text.ts        文字粒子层（衬线字形采样，恒定点集）
  rain.ts        雨丝粒子层
  droplets.ts    玻璃水珠层（2D canvas 覆盖，蜿蜒滑落）
  moon.ts        月相装饰
ui/
  panel.ts       设置面板（schema 生成表单，玻璃质感）
  shell.ts       键盘映射、屏保状态机、idle 检测
```

**样式插件接口**（加样式不改引擎）：
```ts
interface StyleDef {
  id: string;
  title: string;
  settings: SettingSchema[];   // 面板自动生成
  build(ctx: StyleContext): void;    // 建静态粒子
  animate(ctx: StyleContext): void;  // 每帧动态
}
```

## 3. 内容层

| 元素 | 呈现 | 位置 |
| --- | --- | --- |
| 主时间 HH:MM | 衬线字形粒子，秒以副元素呈现（声波/轨道/星尘各有解法） | 居中 |
| 秒 | 依样式：星尘=呼吸亮度，轨道=绕行点，声波=波形振幅 | — |
| 日期 + 星期 | 真实文本小字「10月27日 星期一」 | 主时间下方 |
| 农历 + 节气 | 真实文本小字「九月初七 · 霜降」 | 日期下方 |
| 月相 | 小型粒子月相盘 | 右上或日期行尾 |
| 天气 | 「12° 小雨」小字 | 左上或右上 |
| 世界时钟 | 「纽约 06:32」小字，多城市每 10s 轮换 | 主时间下方副行 |

文本用真实 DOM/CSS 渲染（衬线字体直接可用），粒子只负责视觉主体。
**理由**：小字用粒子点阵在 11px 尺度下无法保证可读性，与「高级感」冲突。

## 4. 视觉规范

### 色温映射（中等偏移，明显可辨）
| 时段 | 主色 | 环境倾向 |
| --- | --- | --- |
| 深夜 23–05 | 深蓝 #8fa8d8 | 整体降亮 25%，安静模式倾向 |
| 清晨 05–08 | 暖金 #e8c88a | 亮度缓慢回升 |
| 白天 08–17 | 象牙 #e9e4d8 | 标准曝光 |
| 黄昏 17–20 | 琥珀 #e0a878 | 暖调，余晖感 |
| 夜间 20–23 | 淡蓝紫 #b8c4e8 | 亮度回落 |

过渡：相邻时段之间 20 分钟线性插值，不瞬切。
样式可覆盖色温映射（如声波样式用冷灰主色），但时段结构不变。

### 硬性预算（沿用）
| 项 | 值 |
| --- | --- |
| 背景 | #0a0a0d |
| 粒子数 | 默认 12,000（可调 4k–30k） |
| 片元亮度钳制 | ≤ 1.0（无泛光后处理） |
| 默认曝光 | 0.72（可调 0.4–1.0） |
| 月相/水珠等装饰 | 计入亮度预算 |
| 验收 | 截图平均亮度 6–18/255，主体居中误差 < 2px |

### 字体
默认：Didot / Bodoni MT / Playfair Display → Georgia 兜底（衬线）。
设置面板可切换衬线 / 无衬线 / 等宽三组字体栈。

## 5. 天气模块

- **数据源**：Open-Meteo（免费免 key）。城市检索用其 geocoding API（支持中文）。
- **设置**：城市输入（带联想候选）；显示「12° 小雨」小字可开关。
- **缓存**：localStorage 30 分钟；离线用旧数据并在小字后标注「· 旧」。
- **降级**：请求失败静默，不弹错，不影响其他功能。

### 天气视觉映射
| 天气 | 背景粒子 | 前景水珠 |
| --- | --- | --- |
| 晴 | 缓慢呼吸，微微上浮 | 无 |
| 阴 | 几乎静止，密度略增 | 无 |
| 雨 | **雨丝**：细长粒子匀速下落，风向偏移 | **玻璃水珠**：随机生成，沿重力+随机游走下滑，路径上吸并小珠、留下渐隐水痕，到屏幕底消失 |
| 雪 | 慢速飘落 + 横向摆动 | 少量贴附水珠（半融感） |
| 雾 | 全局轻微降对比 + 低频漂移 | 无 |

水珠实现：2D canvas 覆盖层（便宜、真实感好），与 WebGL 层合成；
数量上限 60 颗，雨停后 5 秒内全部滑落消失。

## 6. 音乐律动

- **输入**：麦克风（getUserMedia），本地 AnalyserNode，**绝不上传**。
- **映射**：低频 → 呼吸幅度，中频 → 粒子抖动，高频 → 亮度微闪。
- **开关**：任意样式可用（设置面板 + 快捷键 M）；开启时面板显示输入电平条。
- **拒绝授权**：开关灰显 + 提示，不影响其他功能。
- **预算**：律动导致的亮度增量 ≤ 曝光的 +15%，不允许爆闪。

## 7. 番茄钟（独立样式）

- 状态机：IDLE → 工作 25min → 短休 5min →（×4 后）长休 15min。
- 时间戳计时（后台标签页不丢精度）；localStorage 持久化。
- 样式呈现：倒计时数字为主体，阶段色（工作=暖红、休息=青绿），
  粒子呼吸频率随阶段变化。结束时画面有一次「绽放-收束」动画 + 提示音（可关）。
- 时长可设置。

## 8. 屏保模式

- 触发：无任何输入 N 分钟（默认 5，可调 0=关闭）。
- 行为：日期/天气/状态文字淡出，只留主时间；粒子进入慢呼吸（速度 ×0.3）；
  色温随真实时间继续走。任何输入立即恢复。
- 与安静模式独立，可叠加。

## 9. 样式规格（首批）

| 样式 | 主体表现 | 秒的呈现 | 个性 |
| --- | --- | --- | --- |
| 星尘 dust | 衬线字形点阵，恒定点集 | 秒驱动整体呼吸亮度；整分时轻微「绽放」 | 基准样式，最先打磨 |
| 轨道 orbit | 字在中心，粒子沿椭圆轨道环流 | 轨道速度 = 真实秒速；轨道上有亮头表示当前秒 | 天文气质，呼应「星球」原型 |
| 声波 wave | 粒子排成水平波形线，穿过字的后方 | 秒驱动波形相位；分钟一次整周期 | 现代、冷调 |

三样式共享内容层（文字、天气、世界时钟、农历）；差异只在粒子运动。

| 键 | 行为 |

## 12. 技术栈与环境

- Three.js + GLSL ShaderMaterial + Vite + TypeScript strict（不变）。
- 不引入后端；天气/麦克风全部浏览器本地能力。
- 验证管线：Playwright 截图 + Pillow 亮度/构图指标 + 运行时探针（不变）。
- 性能目标：60fps @ 1600×900（12k 粒子 + 60 水珠）。
