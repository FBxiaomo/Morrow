# v3 页面重置设计（杂志编辑风）

> v3.0 · 2026-10-27 · 整页推翻重排
> 方向由用户裁定：整页视觉推翻重排 / 粒子留着但换形态（星野、雾、流体）/ 杂志编辑风。
> 本文是 v3 的权威契约；与 v2 设计冲突处以本文为准。v2 的功能全部保留，视觉全部重做。

---

## 0. 一句话

**时间不再是「粒子拼出来的字」，而是排版；粒子退到背景，成为星野/雾/流体的氛围层。
整页按杂志编辑风重排：大号衬线数字、细线分隔、栏目化元信息、大量留白。**

打开页面应当「判若两页」：一眼是杂志内页的高级感，不是特效演示。

- 竖屏/窄屏：右栏折到时间块下方，单列排布。

## 2. 排版系统

| 元素 | 规格 |
|---|---|
| 大数字 | 衬线栈（Noto Serif SC / 宋体 / Georgia），clamp(96px, 24vh, 220px)，font-variant-numeric: tabular-nums，字距 -0.01em |
| 秒线 | 1px 细线，宽度 = 时间块宽度，accent 色，一分钟从左扫到右（线性、无跳变） |
| running head / footer | 11–12px，字距 0.28em，ink 55% 透明度 |
| 右栏行 | 13–15px 城市名 + 等宽数字时间，行距 1.9，城市名 ink 55% / 时间 ink 90% |
| 细线 | 1px，rgba(ink, 0.14)，只做水平线；全页不出现边框和卡片 |
| 颜色 | bg #0a0a0d，ink #e9e4da，accent #c9a468（暖金）；色温系统保留：整页 ink/accent 随 TempColors 平滑冷暖过渡 |
| 亮度 | canvas 氛围层平均亮度 6–18/255（沿用）；DOM 文字不参与该指标 |

## 3. 粒子氛围层（三形态，对应按键 1/2/3）

粒子**不再描字**，全部预算（≤12,000）投入背景氛围。三形态即三种「气质底噪」：

1. **星野（默认）**：约 4,500 星点，三层景深（近/中/远不同尺寸与漂移速度），
   极慢视差漂移；每 40–90 秒随机一颗流星（细短划线，安静模式停流星）。
2. **雾**：约 6,000 大软颗粒，双层慢速卷动（正弦+噪声），极低对比，像晨雾呼吸。
3. **流体**：约 7,000 点走 curl-noise 流场，细长拖尾感（点沿流向微拉伸），
   流速极慢，形似墨在水中散开。

通用硬规则（沿用 v2）：加性混合；片段亮度钳制 ≤1.0；无 bloom；无硬切（形态切换用 1.2s 淡入淡出）；
视觉运动幅度克制（≤8% 大数字高观感）；安静模式减半动态；「关掉特效它依然能用」（关氛围 → 纯排版页，依然完整）。

- 色温：氛围色取 TempColors.trail / digit 的低亮度混合，随冷暖过渡。
- 律动（M）：低频 → 雾/流体的流速与亮度呼吸；高频 → 星野闪烁。幅度封顶，关闭后回落时间驱动。
- 番茄钟（空格）：秒线变进度线（走满换阶段）；右栏显示「专注 24:31」；阶段切换纯视觉微光。

## 4. 功能保留清单（一个都不丢）

时钟（24/12 制）、日期/星期、农历/节气、天气（Open-Meteo，30 分钟缓存）、世界时钟列表、
番茄钟（25/5/×4→15，时间戳驱动，持久化）、音乐律动（频段包络+面板电平表）、
设置面板（全部 schema：外观/内容/专注/律动/天气/氛围）、安静模式、全屏、色温渐变、
键盘操作、鼠标零反应、本机设置持久化。

变化点：
- 世界时钟从「10 秒轮换一行」改为「竖排常驻列表」（城市沿用设置，每分钟刷新）。
- 样式选择器语义变为「氛围形态」（星野/雾/流体）。
- 雨丝/水珠/月相装饰默认关闭（编辑风不要杂物），设置里保留开关。

## 6. 明确放弃

- 粒子描字（glyphs 采样、数字弹簧形变）退出主视觉（代码保留，供日后彩蛋，不进主线）。
- 秒环、轨道/声波的旧表现形（其功能语义——秒/进度/律动——由秒线与氛围承接）。
- 一切「特效演示感」的表达：光污染、闪烁、过度运动。

## 7. 成功标准（用户视角）

1. 打开页面第一眼：像翻开一页高级杂志，时钟是排版主角，粒子是纸上的雾。
2. 任何时刻截图都经得起看：留白、对齐、字距、细线克制到位。
3. 关掉氛围特效，它依然是个完整漂亮的时钟。
4. 功能一样不少，鼠标永远不打扰画面。
