# V4 · 主题与动态天气

2026-10-27

用户确定：完整主题与深入自定义结合；天气影响整个背景；主要用于电脑浏览器全屏或常驻。

## 当前实现

1. 天幕：轻盈大数字居中，程序绘制的天空与层叠山峦。
2. 数字工作室：浅色底、靠左大数字、抽象圆形背景和底部世界时钟。
3. 窗边：窗框、侧置衬线时钟、窗景与雨天玻璃水滴。
4. 静谧编辑：深色杂志布局、细线、大衬线数字与世界时钟。

主题按各自的外观、背景和内容配置保存；城市、天气选择、专注时长与麦克风设置属于全局。恢复主题默认只影响当前主题的个人搭配。

天气分为真实与手动两种来源。手动天气明确标注为视觉预览，不产生虚构温度。真实天气未配置城市时，使用本地时段的晴空氛围并提示选择城市。下雨、下雪、雾与雷雨驱动背景效果；闪电默认关闭。天气视觉和天气文字可分别关闭。静态模式保留当前风景与天气的静止画面，时钟照常刷新。

背景为本地程序绘制，没有依赖远程壁纸。自定义图片在浏览器内处理为最长边不超过 2560px 的 WebP，保存在本机 IndexedDB；不上传到服务器。字体目前为六套设备字体栈，不保证所有设备拥有同一字体文件。

设置在桌面宽屏以右侧栏显示；主题画廊为中央弹层；较窄视口以弹层完整呈现。原有农历、世界时钟、番茄钟、麦克风律动入口均接入新界面。

## 实现约束

- Canvas 2D，完整动态至多约 30 次绘制/秒，轻量模式至多约 15 次；页面隐藏不绘制。
- 系统减少动态效果时采用静态画面。
- 天气数值与颜色渐进变化；切换主题时版式立即切换。
- 任何字体、背景、天气效果都不能阻断时钟显示。
- 城市搜索先展示候选，不静默替用户选择同名城市；旧设置迁移时按保存名称恢复。
- 每次天气请求有版本标记，晚到的旧响应不能覆盖新城市；更换地点后清除旧城市天气。

## 后续扩展

真实摄影/视频风景、翻页与指针式时钟、自定义字体文件、配置导入导出、更多主题。这些未加入当前版本，避免在主界面方向确认前扩大系统复杂度。
