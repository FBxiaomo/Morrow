# V5 · 写实天气与秒的节奏

## 体验

沿用四个主题和各自的个性化配置。天幕与窗边使用山湖摄影风格背景，工作室采用石材与石膏墙的自然采光，静谧编辑采用蓝调海岸。背景随昼夜和天气调色，天气粒子实时绘制，不是背景图片中预先画好的雨雪。

在「个性化 → 天气 → 画质与互动」中切换：

| 档位 | 表现 | 开销控制 |
| --- | --- | --- |
| 轻量（默认） | 细雨、雪花、薄雾；窗边基础水滴 | 通常约 30 次绘制/秒，不创建数字碰撞与水珠画布 |
| 写实 | 多层雨雪、流动云雾、笔画湿润高光、水珠滑落和雨滴溅射、玻璃折射近似 | 请求约 60 次绘制/秒；雨 700、雪 180、水珠 100、溅射 240、玻璃水滴 48 的数量上限 |

实际帧率取决于设备与浏览器。这里是 Canvas 2D 的视觉模拟，不是完整流体/光线追踪模拟。前景玻璃水滴采样背景产生折射感；数字表面用笔画蒙版与局部高光模拟湿润。

「雨雪与数字互动」和「前景玻璃水滴」可独立关闭。在轻量档或关闭天气效果时禁用对应设置。切回轻量或关闭天气效果时，移除写实画布、粒子与碰撞蒙版，并释放高细节云雾纹理。

动态强度设置仍独立存在：完整、轻量动态、静态。轻量动态约 15 次绘制/秒；写实的粒子减半。静态和系统减少动态效果不推进天气模拟，仍允许时钟正常更新时间；页面隐藏时停止绘制。所有档位使用本地背景资源，加载失败时有程序化风景兜底。

## 秒数

「个性化 → 外观 → 秒的节奏」（内容页也可设置）：

- 隐藏：不显示秒数或秒进度。
- 数字：在主时间右侧显示两位秒数。
- 进度条：细线表示当前分钟的进度，下方显示当前秒数 / 60。
- 数字＋进度条：两者同时显示。

秒进度与专注进度分开，跨分钟直接归零。秒数表现按主题记忆。V4 的秒数开关迁移为「数字＋进度条」或「进度条」，保留原有显示习惯。

## 数字互动

根据浏览器当前字体、字重、字号、字符位置建立像素蒙版，沿雨滴运动线检查碰撞，避免高速粒子穿过细笔画。撞击生成附着水珠与短寿命溅射，水珠长大、滑动并脱离笔画。更换字体/主题、缩放、调整位置、改变时间时重建蒙版；秒数变化时保留仍在笔画内的水珠和正在下落的水滴，不重启整片天气。

## 工作室的天气光

数字工作室是室内场景，雨雪不进入房间，天气改变的是「光」：墙面原有的斜向阳光区随天气变暗、转冷或回暖。实现上在加载背景板时按亮度提取阳光区蒙版（亮度约 192–226 的平滑过渡，覆盖墙面斜光与石台亮带），所有投映只落在蒙版内：

- 晴天：暖金阳光区，云量高时有缓慢掠过的云影；夜晚转为清冷的月光区并整体压暗。
- 阴雨/雷雨：阳光区转冷灰并压暗，区内出现沿窗向下滑落的雨纹；雷雨时整屋与光区同步闪出雷光（受「闪电效果」开关控制）。
- 雪：冷白亮区与飘落的雪光斑；雾：光区散射发白、整屋加一层薄雾。

蒙版与背景板同源，随图片解码一次性生成（约 836×470），读取像素失败时回退到几何斜光蒙版。工作室不创建雨雪粒子画布，时钟保持干燥。

所有粒子共用主绘制循环，没有为每颗雨滴创建计时器。图片与调色底图缓存；只在几何变化时读取裁剪后的字体蒙版，避免逐帧整屏读像素。雪花带远近层次，接触数字后留下少量积雪。

## 验证

- `npm run build`：TypeScript + Vite。
- `npm test`：17 项 Edge 浏览器回归，包含原有主题、天气数据竞态、离线缓存、上传图片和专注行为，以及本次秒数、迁移、真实运动碰撞、滴落、模式切换、静态和手机布局。
- `node artifacts/preview-v5.mjs`：生成四主题、雨/雪、设置页、手机截图，输出 `artifacts/v5-preview-metrics.json`。绘制耗时仅表示当前机器的脚本测量，不等于 GPU 帧率。
- 天气接口测试使用固定响应，不代表当前网络下实时服务的可用性。

参考：用户提供的雨天截图。重点吸收细雨、数字上的湿润高光、字形边缘溅射与深色天气氛围，不复制截图中的手机系统 UI。
