# V6 · 窗边玻璃雨与窗框层次

参考用户指定的 [Lavender-z/demo · 雨特效](https://github.com/Lavender-z/demo/tree/master/%E9%9B%A8%E7%89%B9%E6%95%88%EF%BC%88css%2Bjs%EF%BC%89)，重点借鉴玻璃水滴造成背景折射、凝结的玻璃柔化景色、水痕经过后局部变清晰的视觉思路。本项目独立编写 WebGL shader 与生命周期管理，未引入示例的 Curtains.js、外部图片、代码副本或单独绘制循环。

## 使用

切换「窗边」主题，在「个性化 → 天气」选择写实画质、开启前景玻璃水滴，选择自选下雨/雷雨或连接实际雨天天气。轻量档仍使用简单玻璃水滴，不创建 WebGL。关闭前景玻璃水滴后保留窗外雨雪。

窗边将时钟放在室内：雨在外侧玻璃流动，数字保持清晰。此主题禁用「雨雪与数字互动」控件，保留其他主题原有的全局偏好，切换回去仍能看到数字水珠与溅射。

## 画面顺序

1. 本地摄影背景、昼夜调色与窗外雨雪。
2. 玻璃折射：大小两层下滑水滴、细小驻留水珠、尾部水痕与局部清晰区域。
3. 室内窗框：凹槽、边缘高光、纵向窗梃、横梁、把手与带阴影的窗台。
4. 室内时钟、日期与工具栏。

窗框独立挂在 body 中，设置侧栏只改变 UI 的可用宽度，不拉伸或移动建筑边框。默认时钟在左侧大窗格中，竖梁移到右侧约 77%，横梁在时间和秒进度下方。手机隐藏竖梁和把手，保留细边框与横梁。

## 渲染与回退

- 使用统一的 Landscape 绘制循环，遵循页面隐藏、静态与系统减少动态效果。
- 仅在窗边、写实、玻璃开启且有雨量时创建玻璃渲染器。
- 每片元使用固定数量的场景采样；帧缓冲上限约 180 万像素，背景纹理更新上限约 30 次/秒。
- 切换主题、轻量模式、关闭天气或玻璃时立即删除画布、纹理、程序和缓冲；雨停止后随过渡释放。
- 创建/编译失败或 WebGL context 丢失时退回 Canvas 水滴。静态时 context 丢失也会主动触发一次重绘。
- 没有新依赖、联网纹理或鼠标跟随效果。

## 验证

`npm run build` 通过；22 项 Edge 浏览器测试通过。新增 5 项覆盖真实 shader 绘制、雨位于窗框后方、时钟保持干燥、设置展开时窗框不动、静态/减少动态效果、手机与大屏、资源释放，以及 WebGL 不可用/丢失的回退。

预览脚本：`node artifacts/preview-window-v6.mjs`。导出截图与 `artifacts/v6-window-metrics.json`；本机快照中使用 WebGL，未发现页面运行错误。脚本记录的是当前环境的 CPU 调用耗时，不表示所有设备的实际帧率。
