# 粒子融合工具 · 完整计划 v1.0

> 定位变更：不是「挂在桌面上的时钟」，而是**这个应用本身就是桌面**。
> 打开即全屏，沉浸、无干扰。因此不做 Tauri 窗口挂载，浏览器全屏即可。

## 1. 产品定义

一个**全屏粒子桌面**。核心是时钟，但它是「粒子融合工具」的第一个场景，
后续音乐律动、文字挂件、氛围都以场景形式接入，共用同一套引擎与视觉规则。

三条底线：

1. **关掉特效依然可用**——时钟能看时间，不是纯装饰。
2. **亮度有预算**——不做全屏泛光，参数写死在引擎里。
3. **点击必须准**——落点误差 < 2px，用调试标记验证。

## 2. 架构

```
src/
  core/
    engine.ts     渲染器、相机、拾取、主循环、全屏
    field.ts      粒子场：缓冲、弹簧物理、着色器
    palette.ts    视觉规则常量（亮度预算、配色、尺寸）
    rng.ts        确定性随机
  scenes/
    types.ts      Scene 接口 + SceneContext
    glyphs.ts     字形采样器（数字/符号 → 归一化粒子点集）
    clock.ts      时钟场景
  audio/
    audio.ts      环境音（简化版，只保留铺底 + 交互音）
  ui/
    shell.ts      设置面板、快捷键、全屏、空闲隐藏光标
  main.ts         装配
```

场景接口：

```ts
interface Scene {
  id: string;
  title: string;
  enter(ctx: SceneContext): void;
  update(ctx: SceneContext): void;  // 每帧写 targets
  exit(): void;
}
```

引擎每帧：场景写 targets → 弹簧物理推进 → 上传 GPU → 绘制。
**加功能 = 加一个场景文件。** 引擎不含任何时钟逻辑。

## 3. 时钟场景设计

**主体**：HH:MM 四位数字，粒子组成。等宽字形，位数变化时只动变化的数字，
其余粒子原地不动（字形采样按「数字值」确定性生成，同一个数字永远是同一批点）。

**秒**：一圈细环，粒子沿角度分布，亮度表示当前秒进度（连续推进，非跳变）。
环半径自动包住数字，并随视口缩放。

**日期**：用真实文本渲染，不用粒子——桌面时钟第一要求是可读。

**布局**：数字自然尺寸 digitH = 1.0 世界单位，环半径 = max(钟宽×0.62, digitH×0.95)，
整体按视口缩放，保证四周留白 ≥ 8%。

**动态**：
- 分钟跳变 → 粒子从旧字形飞向新字形（弹簧，约 0.6s 收敛）
- 秒环连续扫过，当前秒附近有轻微光晕
- 全屏空闲 3 秒后光标隐藏、UI 淡出（移动鼠标唤回）

## 4. 视觉规则（硬性参数，写进 palette.ts）

| 项 | 值 | 理由 |
| --- | --- | --- |
| 背景 | #05070c 纯色 | 不用大面积渐变 |
| 粒子总数 | 12,000（数字 9,600 / 环 1,800 / 余量 600） | 够密，不糊 |
| 混合 | 加法，片元内钳制亮度 ≤ 1.0 | 杜绝叠加过曝 |
| 点大小 | 1.0–2.6 px，随距离微衰减 | 近大远小 |
| 主色 | 冷白 #dfe9ff | 数字 |
| 强调色 | 青 #6fe0ff | 秒环、当前分钟 |
| 饱和度 | ≤ 0.6 | 不做彩虹 |
| 全局曝光 | 0.85，可调 0.3–1.2 | 一键压暗 |
| 后处理 | 无泛光 | — |
| 安静模式 | 曝光 ×0.55，运动 ×0.6 | 夜间 |

**验收**：截图平均亮度必须落在 6–18（0–255 灰度），超范围即不合格。

## 5. 交互规则

| 交互 | 行为 |
| --- | --- |
| 点击 | 光标处产生涟漪：局部冲量 + 冲击环扩散，150ms 冷却 |
| 双击 | 切换全屏 |
| F | 全屏 |
| S | 设置面板 |
| 空格 | 安静模式开关 |
| 1/2 | 24h / 12h |

**拾取修正**（上一版的三个错误）：

1. 不再手改 unproject 结果的 z；
2. 不再对已转换的坐标二次乘 matrixWorld；
3. 统一路径：屏幕 → NDC → Raycaster → 与 z=0 平面求交 → points.worldToLocal() → 得到**局部坐标**，
   物理冲量直接在局部空间施加。

调试开关（URL 加 ?debug=1）：在拾取点画红色十字，截图比对误差。

## 7. 风险与对策

- **字形采样抖动**：采样用固定种子，同一数字永远同一批点 → 无抖动。
- **12k 粒子 CPU 物理开销**：约 240k flops/帧，60fps 无压力；不排序（加法混合与顺序无关）。
- **首帧白闪**：初始粒子聚在中心，第一帧即淡入，不做 loading 遮罩。
- **不同屏幕比例**：布局按视口实时计算，窄屏自动缩小，不裁切。
