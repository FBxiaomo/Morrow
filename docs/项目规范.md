## 1. 总则

1. **真相源分层**：`AGENTS.md`（协作入口）→ `docs/项目规范.md`（工程约定，本文件）→ `specs/capabilities/*/spec.md`（行为规格）→ `docs/vN*.md`（历史决策，只读）。冲突时以更靠近本清单左侧的文档为准，并立刻修正右侧。
2. **文档先行**（承袭 `docs/v2设计.md` 的立项原则）：行为级改动先改规格再改代码；实现中发现规格有误，先修规格，再按新规格调整实现。
3. **不留 TODO/FIXME**：代码中不写未完成标记；未决事项进入 `specs/changes/` 提案或能力规格「未决事项」小节。
4. **版本口径**：`package.json`、README 版本记载、设置面板「关于」文案三处必须一致；2026-11-22 已统一为 **0.2.1**。

## 3. 分层架构规范

```
data/（纯逻辑层）  →  ui/（DOM 层）  ←回调→  atmosphere/（渲染层）
        └──────────── main.ts（装配根）────────────┘
```

1. **`src/data/`**：纯 TypeScript，**禁止任何 DOM 副作用**（不 import CSS、不查 DOM、不挂监听）；可依赖 `localStorage` / `IndexedDB` / `fetch` / `Intl`。
2. **`src/ui/`**：组件「自挂载」模式——构造函数创建根元素并 `document.body.append`，`readonly root/dialog` 持有；组件间不互相引用，**一律经 `main.ts` 回调接线**。
3. **`src/atmosphere/`**：所有绘制实现 `dispose()`；不读取 UI 内部状态，**只经 `SettingsStore` / 服务单例取值**。
4. **`src/main.ts`**：唯一装配点。新增服务/组件在此实例化与接线；新增全局定时器、全局监听必须在此登记。
5. **依赖方向**：`ui → data`、`atmosphere → data`；`ui` 与 `atmosphere` 互不依赖（窗框 DOM 例外：`dashboard.ts` 持有窗框并挂 body，层级由 CSS 控制）。
6. **状态广播**：各服务自带监听器集合，不引入事件总线；新「几何变化类」事件可复用 `clock-layoutchange` 模式（DOM CustomEvent + `document.body` 广播）。

## 4. TypeScript 规范

- `tsconfig.json`：`strict: true`、`target ES2022`、`isolatedModules`、`noUnusedLocals/Parameters`、`noFallthroughCasesInSwitch`、`noEmit`。**不放宽**。
- **命名**：
  - 文件/目录：全小写 kebab-case（`window-glass.ts`、`font-picker.ts`）；
  - 类：PascalCase（`SettingsStore`）；服务单例导出：camelCase（`export const pomodoro`）；
  - 常量：SCREAMING_SNAKE（`THEMES`、`GLOBAL_SETTINGS`、`MAX_CATCHUP`）；
  - 设置键：点分 `section.name`，schema `label` 即中文 UI 文案；
  - CSS 类：扁平 kebab（`.clock-time`、`.theme-card`）。
- **模块**：纯 ESM（`"type": "module"`），禁止 CommonJS 产物；副作用导入只允许出现在 `main.ts` 顶部（CSS）。
- **注释语言**：模块头注释用中文；行内解释性注释中英均可，但关键不变量（竞态守卫、迁移、降级链）必须有注释。
- **无运行时日志**：产品路径不使用 `console`；测试探针统一走 `window.desktop` 与各渲染器 `diagnostics` / `stats` getter。

## 5. 设置与存储

### 5.1 设置 Schema（`src/data/settings.ts`）

- 全部用户可调项必须登记在 `GLOBAL_SETTINGS`（37 键，基线 0.2.1），五种 kind：`slider`（钳制到 min/max 并对齐 step）、`toggle`、`select`（options 白名单）、`color`（`^#[0-9a-f]{6}$`）、`text`。
- 校验失败一律**回默认值**，不抛错（损坏数据安全回退由测试覆盖）。
- UI 控件由 `customizer.ts` 的 `group()/control()` 按 schema 生成；控件间联动（禁用/隐藏）写在 `syncControls()`。
- **废弃键政策**：旧键保留 schema 条目作迁移输入（例：`content.seconds` → `secondsStyle`）；确认无消费方的键（当前唯一：`appearance.exposure`）标注「待清理」，不得新增读取方。

### 5.2 存储注册表（新增持久化键必须在此登记）

| 键 | 归属文件 | 内容 | 迁移状态 |
| --- | --- | --- | --- |
| `desktop.v2.settings` | data/settings.ts | 扁平设置值 `Record<string, number\|boolean\|string>` | 现役 |
| `desktop.v2.pomodoro` | data/pomodoro.ts | 专注快照 `{active, phase, startedAt, pausedAt, cycle, task}` | 现役 |
| `horloge.theme-profiles.v1` | data/themes.ts | 每主题个性化键值 | 现役；随 Morrow 提案迁移 |
| `horloge.weather.v4` | data/weather.ts | `{location, info, fetchedAt}`，TTL 30 分钟 | 现役 |
| `horloge.weather-location.v1` | data/weather.ts | 最近城市 `{name, latitude, longitude}` | 现役 |
| `horloge.focus-history.v1` | data/pomodoro.ts | 完成记录，上限 100 条 | 现役 |
| IndexedDB `horloge-images` / store `images` | data/themes.ts | 自选背景 Blob，键 = 主题 id | 现役 |
| PWA 缓存 `horloge-shell-v1` | public/sw.js | 核心界面离线缓存 | 现役；随 Morrow 提案迁移 |

- **新键规则**：带 `.vN` 后缀；构造函数内做防御性解析（损坏 → 回默认/idle，不抛错）；写入失败必须经 `onPersistenceChange` 类通道让 UI 呈现「仅本次有效」。
- **清空数据契约**：清空入口必须删除上表全部键与 IndexedDB 库（含二次确认交互）。

### 5.3 配置导出/导入

- 导出：`{ app, version, exportedAt, settings }` JSON，文件名 `末时钟配置-YYYY-MM-DD.json`，体积上限 1MB 校验。
- 导入：校验 `app` 标识 + 版本号 + 逐键 schema 合法性；失败文案「无法导入：文件格式或版本不受支持」。
- 导出 `app` 标识当前仍为 `'horloge-finale'`（兼容旧备份），迁移规则见 Morrow 提案。

## 6. CSS 与视觉规范

- **按功能拆分 8 文件**，由 `main.ts` 顶部副作用导入；0.2.x 发布打磨类样式追加到 `liquid-settings.css`（分层覆盖），不重写旧规则。
- **状态通道**用 `body[data-*]`（见 `AGENTS.md` §3）；视觉参数用 `:root` CSS 变量（`--clock-*`、`--glass`、`--accent` 等）。
- **硬性下限**：界面文字 ≥ 11px（`polish.spec.ts` 断言）；触控目标 ≥ 40px（工具条 44px）；`focus-visible` 必须有轮廓。
- **全局短路**：`prefers-reduced-motion` 关闭全部动画；`document.hidden` 停止背景绘制；`[hidden] { display: none !important }`。
- **移动适配**：`100dvh`、`safe-area-inset`；≤500px 横屏启用独立紧凑构图（先移除装饰与次要信息）。
- ⚠️ **已知残留**：`weather.css` 移动端秒说明与 `desktop.css` 工具条 kbd 两处 10px 文字（< 700px 断点），严格 11px 契约的收尾属于未决事项（见 §12）。

| 写实档帧预算 | 16ms | landscape.ts |

- 体积云节流：结果 key 缓存 + 10/18fps 限频。

## 8. 交互与可访问性规范

- **快捷键契约**（变更必须同步 README 与设置面板说明行）：`1–4` 切主题 · `S/Esc` 设置/关闭 · `F` 全屏 · `H` 纯净显示 · `T` 12/24 制式 · `空格` 专注打开/暂停/继续 · `M` 麦克风。
- **键盘守卫**：输入控件、按钮空格/回车、长按 repeat、Ctrl/Meta/Alt 组合一律不触发全局快捷键；Esc 关闭面板后 400ms 内空格丢弃（`wasJustDismissed`）。
- **闲置**：3600ms 无输入 → `body.idle`（光标隐藏 + 工具条淡出）；设置/专注/纯净打开时、焦点在控件、触屏（`pointer: coarse`）不隐藏。
- **语义**：装饰层 `aria-hidden`；计时与进度用 `role="timer"/"progressbar"`；状态行 `role="status"` + `aria-live`；tab 用 `aria-current`。

## 9. 错误处理与降级规范

1. **防御性解析**：localStorage / 导入数据解析必须 try/catch，损坏回默认（附注释，如 pomodoro.ts "Damaged storage falls back to idle."）。
2. **用户可见反馈**：所有失败终态经 `customizer.notify()` toast 或状态行文案呈现；天气用中文 `status` 字符串自述（「正在显示上次天气」等）。
3. **竞态防护**：跨帧/网络异步一律 `revision` 计数守卫（天气、自选图片、音频、城市搜索四处为范本）。
4. **网络超时**：`AbortSignal.timeout`（城市搜索 10s、天气 12s）；失败不自动重试轰炸，等 30 分钟周期或 `online` 事件。
5. **WebGL 降级链**：创建/编译失败 → Canvas 回退；`webglcontextlost` → 同回退；关闭设置项 → `dispose()` + `WEBGL_lose_context` 即时释放。
6. **能力探测失败的产品决策**：WakeLock 不支持 → 关闭设置项并 toast，不静默维持开启态。

## 10. 测试规范

- 框架：Playwright，`tests/` 目录；配置锁死：`channel: msedge`、`127.0.0.1:5192`、`workers: 1`、`fullyParallel: false`、`timezoneId: Asia/Shanghai`、`viewport 1440×900`。
- 基线 **40 项执行用例**（7 个 spec 文件）；行为级改动必须新增/更新对应用例，**全量绿才算完成**。
- **驱动方式**：一律 `window.desktop.*` 探针驱动真实服务对象；禁止为测试在产品代码里开只读后门。
- **Mock 边界**：Open-Meteo 两个域名与 BigDataCloud 地名解析域名（`api.bigdatacloud.net`）必须 `route.abort()` 或固定 mock；时钟用 `page.clock.setFixedTime`。
- **视觉断言**：动画/静态用截图 SHA-256 指纹（同帧重复渲染一致性），不做像素金盒回归；布局断言用 paintedBox 两两碰撞。
- **验收制品**：截图与指标输出 `artifacts/<主题>-<日期>/`，属开发期制品，不进产品、可归档。
