# 能力规格 · 交互层（interaction-shell）

> 适用版本：0.2.1（反向成文） · 主要代码：`src/ui/shell.ts`、`src/main.ts`（pure 模式与 Esc 分发）、`src/desktop.css`

## 概述

键盘契约、工具条与闲置行为、纯净显示模式。交互层的核心价值是「低干扰」：无输入时界面隐去，操作全部有守卫、可预期、触屏友好。

## 需求

### 键盘契约

- **FR-SH-01** 系统应支持快捷键：`1`–`4` 切换主题 · `S` 设置 · `Esc` 关闭或退出 · `F` 全屏 · `H` 纯净显示 · `T` 12/24 制式 · `空格` 专注打开/暂停/继续 · `M` 麦克风律动开关。契约变更必须同步 README 与设置面板说明行。
- **FR-SH-02** 当焦点位于输入控件、或按键发生在按钮的空格/回车语义内、或按键为长按 repeat、或带有 Ctrl/Meta/Alt 修饰时，系统应**不**触发任何全局快捷键。
- **FR-SH-03** 当 Esc 用于关闭面板/纯净显示后 400ms 内到达空格时，系统应丢弃该空格（防 Esc 关闭残留触发按钮，见 focus 规格 FR-FOCUS-16）。
- **FR-SH-04** 当 Esc 被按下时，系统应按优先级处理：关闭设置面板 → 关闭专注面板 → 退出纯净显示；纯净显示下 Esc 优先退出纯净。

### 工具条与闲置

- **FR-SH-05** 工具条应包含：主题、专注（活跃时显示剩余时间并高亮）、个性化、纯净显示、全屏按钮；鼠标移动/指针按下/按键/焦点变化应唤醒工具条。
- **FR-SH-06** 系统应在 3600ms 无输入后进入闲置态（`body.idle`）：光标隐藏、工具条淡出下移。
- **FR-SH-07** 以下情况系统应**不**进入闲置隐藏：设置/专注/纯净面板打开时、焦点位于可交互控件、触屏设备（`pointer: coarse`）。
- **FR-SH-08** 工具条按钮触控目标应 ≥ 44px。

### 纯净显示

- **FR-SH-09** 当用户按 `H` 或点击纯净按钮时，系统应进入纯净模式：隐藏顶栏、底部信息、页脚与眉头说明，时钟垂直居中，只保留时间与用户选择的信息；右下角呈现「退出纯净显示 · H」入口。
- **FR-SH-10** 进入纯净显示时，系统应自动关闭设置与专注面板，并以 toast 提示退出方式。
- **FR-SH-11** 纯净显示应始终可退出（`H`/`Esc`/右下角按钮，有专项测试断言）。

### 指针与触屏

- **FR-SH-12** 系统应在触屏与键盘操作时不自动隐藏工具条（与 FR-SH-07 一致，README 契约）。
- **FR-SH-13** 全屏请求（`F`）失败或被浏览器策略拒绝时应不破坏主界面。

## 设计约束与不变量

- 快捷键处理唯一入口 `Shell.onKey`；新增全局快捷键必须在此登记并同步三个文档位（README 表格、设置面板说明行、本规格 FR-SH-01）。
- 纯净模式经 `body.pure-mode` 类驱动；CSS 层不承载判断。
- `body.dataset` 状态通道与闲置类互不重叠（`idle` 与 `pure-mode` 可共存，层级由 CSS 决定）。
