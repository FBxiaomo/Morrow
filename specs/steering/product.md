# 产品定位 · Morrow

> 长期稳定事实。改动本文件需要显式的产品决策讨论，不随日常变更更新。
> 基线 0.2.1。

## 一句话定位

**为学习、办公与休息提供低干扰的天气氛围时钟**——打开即全屏，时间一眼可见，天气成为氛围而非信息噪音。

## 目标用户（假设，待验证）

- 学生、居家办公者：需要一个「开始一段专注」的仪式感工具；
- 桌面美化爱好者：把浏览器窗口/副屏当作氛围桌布；
- 副屏与桌边平板用户（产品优先形态）。

## 核心使用闭环

```
打开自己的空间（四主题之一） → 开始一段专注（任务意图 + 时长）
  → 到时收到反馈（页面 + 可选系统通知） → 下次继续使用（今日记录沉淀在本机）
```

## 产品原则（承袭历史决策）

1. **关掉特效依然可用**——时钟能看时间，不是纯装饰（v1 三条底线之首，仍然成立）。
2. **低干扰**：无账号、无推送、无红点；全部数据本机。
3. **诚实的降级**：天气断网明示「上次天气」；存储失败明示「仅本次有效」；WebGL 失明即回退 Canvas——任何功能不允许「看起来在工作」。
4. **每主题一个世界**：四主题各自独立配置，切换主题 = 切换一个空间，而非换肤。
5. **文档先行**：v2 立项原则「改动先改文档再改代码」，SDD 是它的正式化。

## 明确非目标

- 不做支付、账户、云同步（README 契约）。
- 不做多语言 i18n 框架（中文 / zh-CN 单语）。
- 不做窗口挂载桌面（v1 决策：浏览器全屏即可）。
- 不做粒子描字时钟主线（v3 决策：粒子退为氛围，已从主链路摘除）。

## 商业化前置条件（P0 红线）

- 天气数据当前直连 Open-Meteo 公共接口；**正式商业发布前**必须：① 更换符合商用条款的服务方案；② 密钥、限流、预算控制放到可信服务端。在此之前禁止任何客户端密钥。
- 未验证项清单：真实移动设备、跨浏览器实机、持续能耗、目标用户访谈、付费意愿（详见 `docs/项目规范.md` §12）。
